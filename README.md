# 🛡️ El Guardián - Sistema de Videovigilancia Móvil

**El Guardián** es un sistema integral de seguridad que reutiliza dispositivos móviles para convertirlos en cámaras de monitoreo inteligente en tiempo real con transmisión de baja latencia.

## 📱 Módulos del Proyecto

* **`guardian-cam`**: Aplicación de captura de video en segundo plano orientada al dispositivo emisor (cámara exterior).
* **`guardian-viewer`**: Aplicación cliente para la visualización remota en tiempo real y recepción de alertas.
* **`guardian-server`**: Servidor de señalización (Signaling Server) basado en WebSockets para enlazar ambos dispositivos.
